How to add a new course

Courses are 100% data-driven: two JSON files are all you need. No code changes are required to register a new certification.

1

Create the question bank

Add a your-course.json file inside public/certifications/ containing an array of questions.

2

Register the course

Add one entry to public/certifications/courses.json with the course name, description and the fileName of the question bank.

Question fields reference

question — the question text. To make it multi-choice write Choose two…/Choose three… or use a multi-letter correct_answer.
options — an object mapping letters (A–E) to the option text.

discussion, vote_counts, community_answer, most_voted, images and is_hotspot are optional but enrich the practice/review experience.
